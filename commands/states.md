---
description: Построить матрицу состояний по спецификации
---

Построй матрицу состояний по спецификации: $ARGUMENTS

Используй скилл `state-matrix` и иди по его шагам, не меняя порядок:
параметры по одному → состояния списком → правила по одному → матрица.

Держись стиля из скилла: коротко, таблицами, каждое сообщение начинается
строкой вида `Шаг 1 из 4 · Параметры · 2 из 5`, любой вопрос — с конкретными
вариантами ответа. Содержимое пиши живой разметкой, не в кодовых блоках.

Модель меняй только тулами `sm_*`. Числа называй только те, что вернул `sm_build`.
