# Оформление заказа

## §1 Окружение
Виджет встраивается в хост. Брейкпоинт (mobile/tablet/desktop) определяется
один раз при загрузке и в рантайме не меняется.

## §2 Загрузка корзины
Виджет запрашивает `GET /api/cart`. Пока ответ не пришёл — скелетон формы.
Ошибка — заглушка с кнопкой «Повторить». Пустая корзина — «Корзина пуста».

## §3 Сумма
Сумма приходит в копейках. Ноль допустим — бесплатный заказ оформляется без
выбора оплаты. Лимит 999 999 900 копеек, выше — ошибка 422.

## §4 Промокод
Поле промокода доступно только авторизованным. Гость поля не видит.
Промокод может быть валидным или истёкшим; истёкший перечёркивается.

## §5 Состояния
- Загрузка — пока корзина не пришла
- Пустая корзина — заказ оформить нельзя
- Ошибка сети — с кнопкой повтора
- Бесплатный заказ — сумма ноль, оплата не запрашивается
- Оформление — обычный случай
