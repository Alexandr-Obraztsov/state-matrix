# На что смотреть у разных типов параметров

Справочник для поиска значений и корнер-кейсов. Это **не анкета**: ответы нигде
не хранятся и не требуются. Пройдись по строчкам своего типа и проверь, не
упустил ли значение, которое спека называет, а ты не заметил.

Нашёл значение — оно идёт в `all_values`. Не нашёл, но подозреваешь, что оно
существует, — это вопрос пользователю, а не догадка.

---

## Число

| На что смотреть | Какие значения даёт |
|---|---|
| нижняя и верхняя границы | `min`, `max`, а также `min-1` и `max+1` |
| ноль | осмыслен, запрещён или означает «не задано» |
| отрицательные | возможны ли вообще |
| целое или дробное | дробное там, где ждут целое |
| единицы измерения | миллисекунды против секунд, копейки против рублей |
| значение по умолчанию | и отличается ли «не передано» от него |

Вне матрицы: `NaN`, бесконечность, переполнение int32.

## Денежная сумма

Всё от числа плюс:

| На что смотреть | Какие значения даёт |
|---|---|
| минимальная единица | одна копейка — часто отдельный случай |
| ноль | бесплатный заказ обычно отдельное состояние |
| лимит операции | сумма выше лимита |
| округление | суммы, где округление меняет итог |
| возврат | отрицательная сумма |

## Строка и поле ввода

| На что смотреть | Какие значения даёт |
|---|---|
| обязательность | пустая строка |
| строка из одних пробелов | отличается ли от пустой — частый баг |
| максимальная длина | `maxLen` и `maxLen+1` |
| обрезка пробелов по краям | где обрезает, а где нет |
| формат или маска | значение, не подходящее под формат |
| интерпретация содержимого | markdown, html, шаблонные подстановки |

Вне матрицы: эмодзи, письмо справа налево, переводы строк, очень длинное слово
без пробелов, разметка внутри текста.

## Перечисление

| На что смотреть | Какие значения даёт |
|---|---|
| полный список | все значения, а не только упомянутые в примерах |
| значение по умолчанию | и что при его отсутствии |
| взаимоисключающие или комбинируемые | если комбинируемые — это не перечисление |

Вне матрицы: значение, которого нет в списке, — пришло с бэкенда после релиза.

## Идентификатор

| На что смотреть | Какие значения даёт |
|---|---|
| сущность существует | и отдельно — не существует |
| чужая сущность | доступ к чужому ресурсу проверяется? |
| формат | некорректный идентификатор |

## Список

| На что смотреть | Какие значения даёт |
|---|---|
| правило ноль-один-много | пусто, один элемент, несколько — часто выглядят по-разному |
| максимальная длина | и что при превышении |
| порядок элементов | значим ли |
| дубликаты | допустимы ли |

Вне матрицы: элемент с пустыми полями, вложенность глубже ожидаемой.

## Дата и время

| На что смотреть | Какие значения даёт |
|---|---|
| прошлое, настоящее, будущее | какие допустимы |
| граница суток | 23:59 и 00:01 |
| таймзона | хранения и отображения |
| формат на входе | некорректная дата |

Вне матрицы: переход на летнее время, 29 февраля, нулевая эпоха.

## Логический флаг

| На что смотреть | Какие значения даёт |
|---|---|
| значение по умолчанию | |
| «не передан» | отличается ли от `false` |
| что меняет | поведение или только внешний вид |

## Ответ сервиса

| На что смотреть | Какие значения даёт |
|---|---|
| стадии | ожидание, успех, ошибка |
| пустой успешный ответ | пустой список — отдельное состояние |
| частичные данные | часть полей пришла пустой |
| документированные коды | каждый код, у которого свой экран |

Вне матрицы: таймаут, потеря авторизации посреди работы, ответ не по схеме,
ответ пришёл после ухода со страницы.

## Ошибка

| На что смотреть | Какие значения даёт |
|---|---|
| где показывается | у поля, баннером, экраном целиком — разные состояния |
| повтор действия | есть ли и сколько попыток |
| судьба введённых данных | сохраняются или теряются |
| когда исчезает | |

## Права и роль

| На что смотреть | Какие значения даёт |
|---|---|
| полный список ролей | включая неавторизованного |
| владелец ресурса | отличается ли от обычного пользователя |
| отказ: 403 или 404 | 403 на скрытый ресурс подтверждает его существование |
| смена прав в сессии | |

## Загрузка файла

| На что смотреть | Какие значения даёт |
|---|---|
| допустимые типы | и файл неподходящего типа |
| лимит размера | и файл больше лимита |
| несколько файлов сразу | |
| отмена загрузки | |

Вне матрицы: нулевой размер, имя с юникодом, двойное расширение, битый файл.

## Размер экрана, язык, фича-флаг

| На что смотреть | Какие значения даёт |
|---|---|
| различаемые варианты | брейкпоинты, поддерживаемые языки, состояния флага |
| меняется ли в рантайме | поворот экрана, переключение языка |
| что меняется | только вёрстка или и поведение |

Если меняется только вёрстка и в спеке нет отдельного описания — это не
параметр матрицы, а замечание к вёрстке. Отправь в `sm_exclude` с причиной.
