# Классы находок

Их три. Два блокируют разбор: пока они есть, матрицу читать рано.

## Блокирующие

**`CEILING` — строк больше ста.** Не «слишком сложно», а плохо выбранная граница.
Сообщение печатает вклад каждого параметра — во сколько раз он умножает матрицу.
Сначала ищи правила свёртки в спеке. Если их нет — это несколько систем в одном
документе, и правильный ответ: предложить разбиение. Поднимать потолок нельзя.

**`RULE_OVERLAP` — два правила схлопывания применимы к одной строке.** Порядок
проверок не определён. Частый случай: «нет прав → 403» и «ресурса нет → 404»
пересекаются, а 403 на несуществующий ресурс подтверждает его существование.
Спроси, какая проверка идёт первой.

## Предупреждение

**`UNDEFINED` — строки без назначенного состояния.** Основной улов. По каждой:
назначить состояние через `sm_assign`, запретить комбинацию правилом, либо
сказать пользователю, что это дыра в спеке.
